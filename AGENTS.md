# Human V2

Browser-based educational optimization arena. Parent Fleet instructions apply.
Use pnpm, TypeScript, React, Vite, and the shared pure model in `src/model/`.
Track feature work in https://github.com/Significant-Hobbies/human-v2/issues/1.

## Commands

- `pnpm dev`: browser plus local Worker/D1, http://localhost:5317.
- `pnpm test`: deterministic model and real local Worker/D1 integration checks.
- `pnpm test:e2e`: production-preview browser workflows and accessibility.
- `pnpm check`: typecheck and lint.
- `pnpm build`: browser and Worker artifacts.
- `pnpm preview`: local production preview, http://localhost:44173.

Never invent physiological effects. Every score, cost, limit, and explanation
must come from the versioned simulator. Reject invalid configurations at the
API; never trust a client score. Count net changed parameters, not edit actions.
Preserve experiment context and never silently reinterpret old versions.
Animal presets are explicit abstractions, not transplantation predictions.
Materia is a related archived reference; do not restore its body UI or medical
content. Owner selected Life Theatre B on 2026-10-01 ("b but much better"), superseding the earlier Systems Lab A.
No commit, push, deploy, remote migration, cloud resource, credential, or
production configuration changes without an explicit owner request.

## Current surface and calibration boundary

Home.tsx is one homepage connected to pinned local Pulse4.4.0. Native adapter
scripts/physiology.py and physiology.mjs run through scripts/server.mjs, not
the Cloudflare Worker. No substitute runtime or invented effects. Six controls
are actual engine mechanisms; combined output does not identify each edit’s
causal contribution. Retain native rejection, convergence and version checks.

Only source-audited Hypoxia and RespiratoryAlkalosis flags may be surfaced. Known
faulty hypocapnia flags are excluded. Threshold-entry timestamps come from native
logs; subsequent sample times must remain separately labeled. Dense-window means
are required for brain-flow comparisons. Rate motion is illustrated, not anatomy
measurement. Unsupported mass/space/surgery/chronic costs remain unknown.

AnnualHome.tsx, NCHS2023 model/data, prior App.tsx and legacy scenarios remain
preserved. No scientifically calibrated modified-organ aging, fatal year or cause
is implemented. Owner chose scientific outcomes, not fictional mortality curves.
